# SchemeAI Evaluation Set

`cases.jsonl` contains 40 hand-labeled synthetic student profiles spanning the four system status tiers and includes official-source retrieval queries.

`multilingual_queries.jsonl` contains English, Kannada and Hindi retrieval cases. Kannada/Hindi explanation quality is marked `human_review_status: pending` until a native speaker reviews the actual generated responses.

Do not use these synthetic profiles as evidence of real-world accuracy. They are a reproducible benchmark fixture. Real-world validation requires consented stakeholder data and a documented labeling protocol.
